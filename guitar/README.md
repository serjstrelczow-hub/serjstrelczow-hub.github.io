# Гитара: аккорды и тюнер — версия для iPhone (веб-приложение)

Порт Android-версии 1.2. Чистый HTML/CSS/JS без сборки: эта папка целиком выкладывается на любой HTTPS-хостинг.

## Установка на iPhone
1. Откройте ссылку на приложение **в Safari** (не в Telegram/Chrome).
2. Нажмите **«Поделиться»** (квадрат со стрелкой вверх) → **«На экран „Домой“»** → **«Добавить»**.
3. Запускайте с иконки «Гитара» — откроется на весь экран, без адресной строки, работает без интернета.
4. При первом запуске тюнера нажмите «Включить тюнер» и разрешите микрофон.

## Что умеет
- Поиск песен на amdm.ru (си = H) и mychords.net (си = B), сохранение в память (IndexedDB), избранное ★.
- Смена тональности ±11 с учётом H/B, совет по каподастру, схемы аккордов по нажатию.
- Автопрокрутка: кнопка ▶, скорость 0.25–3× на ходу (запоминается для песни), отсчёт 3-2-1, нажатие на текст — пауза.
- Тюнер (микрофон + YIN): «N струна — нота · Гц», стрелка, «Подтяни ↑ / Ослабь ↓ / В строе ✓», гриф с ✓,
  эталонный звук струны (Карплус — Стронг) с повтором. 6/7/12 струн, русская семиструнная, бас 4/5, укулеле, свой строй, A4 432–446 Гц.
- Метроном 30–250, 1–12 долей, акцент, Tap. Настройки как в Android. Экспорт/импорт песен в файл.

## Прокси для поиска
Браузер не может читать amdm.ru и mychords.net напрямую (нет CORS), поэтому поиск идёт через прокси.
Адреса прокси берутся из `proxy.json` (`{"proxies": ["https://…/"]}`) или из «Настройки → Сервер для поиска».
- `proxy/worker.js` — прокси для Cloudflare Workers (бесплатно): dash.cloudflare.com → Workers & Pages → Create →
  Hello World → Edit code → вставить файл → Deploy. Полученный адрес `https://имя.аккаунт.workers.dev/` вписать в `proxy.json` или в настройки.
- `proxy/server.js` — тот же прокси на Node.js (`node proxy/server.js`), для любого сервера.
Прокси пропускает только amdm.ru и mychords.net.

## Тесты
- `node tests/music.test.mjs` — транспонирование (в т. ч. H/B), капо, YIN на синтетических щипках.
- `node tests/e2e.mjs <url> <proxy> <папка>` и `node tests/tuner.mjs <url> <папка>` — headless Chrome, экран iPhone;
  тюнер проверяется синтетическим тоном: `?testtone=82.41` вместо микрофона.
